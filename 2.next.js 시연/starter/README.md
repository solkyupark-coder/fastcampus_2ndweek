# 대지 조회 스타터

Next.js 앱입니다. 실행하면 VWorld 지도가 뜨고, 클릭하면 그 지점의 지번 주소가 나오고,
LH 연구 부록에서 뽑은 서울시 노후 매입임대 838필지가 지도에 찍혀 있습니다.

여기서부터 필지 경계 → 용도지역 → 건물 → 규모검토 순으로 채워 나갑니다.

## 실행

```bash
npm install
```

```bash
cp .env.example .env.local
```

`.env.local` 을 열어 본인 VWorld 키를 넣습니다.

```bash
npm run dev
```

`http://localhost:3000` 으로 접속합니다.

## VWorld 인증키 발급

무료입니다.

1. [vworld.kr](https://www.vworld.kr) 가입 → **오픈API** → **인증키 발급**
2. **활용 API**: `2D 지도 API`, `지오코더 API` 체크
3. **서비스 URL**: `localhost` 입력

## 키는 `.env.local` 에 둡니다

키를 코드에 직접 적으면 깃허브에 올리는 순간 공개됩니다.
그래서 키는 `.env.local` 에 두고, 이 파일은 커밋하지 않습니다.

| 파일 | 내용 | 깃허브에 올라가나 |
| --- | --- | --- |
| `.env.example` | 껍데기. 팀원이 보고 따라 만듦 | **올라감** |
| `.env.local` | 실제 키 | **안 올라감** (`.gitignore` 의 `.env*`) |

> 수업 배포본에는 강사 키가 든 `.env.local` 이 들어 있습니다.
> 수업이 끝나면 본인 키로 바꾸세요.

### 그리고 이번에는 진짜로 숨겨집니다

`.env.local` 의 값은 **서버에서만** 읽힙니다. 브라우저로 내려가지 않습니다.

```
브라우저  →  /api/vworld-tile   →  api.vworld.kr
             (내 서버, 키 보관)      (키를 붙여 호출)
```

개발자도구 Network 탭을 열어 보면 브라우저가 부르는 건 `/api/vworld-tile` 뿐입니다.
키는 보이지 않습니다.

> 참고로, Next.js 에서 `NEXT_PUBLIC_` 으로 시작하는 환경변수는 브라우저 코드에 그대로 박힙니다.
> 키에는 절대 쓰지 마세요. 이 프로젝트가 `VWORLD_KEY` 라고만 이름 지은 이유입니다.

## CORS — 왜 서버를 거치나

브라우저에서 `api.vworld.kr` 을 그냥 `fetch` 하면 이런 에러가 납니다.

```
Access to fetch at 'https://api.vworld.kr/...' has been blocked by CORS policy:
No 'Access-Control-Allow-Origin' header is present on the requested resource.
```

내 페이지(`localhost:3000`)와 VWorld(`api.vworld.kr`)는 **출처가 다릅니다.**
출처가 다른 응답을 자바스크립트가 읽으려면 그 서버가 허락 헤더를 보내야 하는데, VWorld 는 안 보냅니다.

**VWorld 에 `localhost` 를 등록한 것과는 다른 이야기입니다.**

| | 무엇을 정하나 | 결과 |
| --- | --- | --- |
| 도메인 등록 | VWorld 가 **응답을 줄지** | 통과 |
| CORS | 브라우저가 **JS에게 읽게 할지** | 차단 |

그래서 지도 타일(`<img>`)은 나오는데 `fetch` 만 막힙니다.
`<img>` 와 `<script>` 는 CORS 검사 대상이 아니거든요.

**서버끼리는 CORS 가 없습니다.** 브라우저의 규칙이기 때문입니다.
`app/api/vworld/route.ts` 가 대신 호출하고 결과만 돌려줍니다.
키를 숨기는 효과는 덤입니다.

## 파일 구조

```
starter/
├─ app/
│  ├─ MapView.tsx              ← STEP 1~4. 실습은 여기서
│  ├─ page.tsx  layout.tsx  globals.css
│  └─ api/
│     ├─ vworld/route.ts       ← VWorld API 프록시 (CORS·키)
│     └─ vworld-tile/route.ts  ← 배경지도 타일 프록시 (키)
├─ public/data/
│  └─ 필지목록.csv             ← LH 연구 부록 838필지
├─ .env.local                  ← 내 키 (깃허브에 안 올라감)
├─ .env.example                ← 키 껍데기
└─ README.md
```

## 지도가 안 나올 때

| 증상 | 확인할 것 |
| --- | --- |
| 회색 화면만 | `.env.local` 을 만들었는지, 키가 맞는지 |
| 500 에러 | 터미널에 `VWORLD_KEY 미설정` 이 찍혔는지 |
| 타일이 깨져 나옴 | VWorld 서비스 URL 에 `localhost` 를 등록했는지 |
| 주소가 안 나옴 | Network 탭에서 `/api/vworld` 응답을 열어 보기 |

브라우저 개발자도구(F12) → Console / Network 를 같이 보세요.
**무엇이 실패했는지 눈으로 확인하는 습관**이 이 수업의 절반입니다.

## 이 스타터가 하는 일

```
지도 클릭
   └→ 경도 / 위도
        └→ /api/vworld  (내 서버가 키를 붙여 호출)
             └→ VWorld 지오코더
                  └→ "서울특별시 관악구 신림동 1573-28"
```

좌표가 주소가 되고, 주소가 PNU 가 되면 그 필지에 대한 **공공데이터의 열쇠**가 생깁니다.
다음 시간에는 이 PNU 로 필지 경계를 그리고, 용도지역을 조회하고,
그 땅에 무엇을 얼마나 지을 수 있는지까지 계산합니다.
